# WFU10 Gremium verwalten

Nach der konstituierenden Sitzung muss die Besetzung des Gremiums in **Elektra** eingepflegt werden. Im Folgenden erfahren Sie, wie Sie die Gremienmitgliedschaften an Ihrem Standort anlegen.

Um Kandidierende nach der Wahl in eine Gremienmitgliedschaft zu übernehmen, rufen Sie zunächst die Wahlfunktion **9) Ergebnisse melden** auf.

![](img/image228.png)
*Übersicht der Wahlfunktionen*

Scrollen Sie anschließend nach unten, bis die **Sitzverteilungs-Tabelle** angezeigt wird.

![](img/image229.png)
*Kandidaten ins Gremium übernehmen*

Dort können Sie wählen, ob Sie **einzelne Kandidierende** (1) oder **alle Kandidierenden gleichzeitig** (2) in das Gremium übernehmen möchten.

## Übernahme einzelner Kandidaten

Wählen Sie die Schaltfläche **„Ins Gremium übernehmen"** aus. Daraufhin öffnet sich ein Dialog, in dem Sie die Gremienmitgliedschaft detailliert festlegen können. In der obersten Zeile wählen Sie aus Listen die Eigenschaften, die die Mitgliedschaft definieren:

<div className="fieldTable">

| Feld | Bedeutung |
| --- | --- |
| Gremienmitgliedsart | Legt fest, ob es sich z. B. um ein gewähltes Mitglied, ein Ersatzmitglied oder eine Entsendung handelt. |
| Gremienrolle / Funktion | Bestimmt, welche Aufgabe oder Funktion das Mitglied im Gremium wahrnimmt. |
| Gremienrechte | Legt fest, welche Befugnisse das Mitglied im Gremium besitzt. |

</div>

![](img/image230.png)
*Modaldialog: Gremium-Mitglied hinzufügen*

Zusätzlich können Sie angeben, **ab wann die Mitgliedschaft gilt** („Sitz gilt von") und **wann sie endet** („Sitz gilt bis einschließlich").

![](img/image231.png)
*Gremium-Mitglied hinzufügen: Amtszeit*

## Übernahme aller Kandidierenden

Alternativ zur individuellen Übernahme können Sie alle Personen gleichzeitig in das Gremium übertragen. Wählen Sie dazu die Schaltfläche **„Alle ins Gremium übernehmen"**.

![](img/image232.png)
*Alle Kandidaten ins Gremium übernehmen*

Anschließend werden sämtliche Kandidierende übernommen. Personen mit Sitz werden automatisch als **gewähltes Mitglied** angelegt, Personen ohne Sitz als **Ersatzmitglieder**.

## Gremium verwalten und weitere Mitglieder erfassen

Um das angelegte Gremium zu verwalten, rufen Sie die Wahlfunktion **10) Gremium verwalten** auf.

![](img/image233.png)
*Aufruf WFU10*

Dort erhalten Sie eine Übersicht über alle bislang erfassten Gremienmitgliedschaften. Um eine bestehende Mitgliedschaft zu bearbeiten, wählen Sie das Stift-Symbol.

![](img/image234.png)
*Schaltfläche Gremium-Mitgliedschaft ändern*

Möchten Sie eine Mitgliedschaft für eine Person anlegen, die in **Elektra** nicht als Kandidierende erfasst wurde, wählen Sie die Schaltfläche **„Neue Person als Gremium-Mitglied hinzufügen"**.

![](img/image235.png)
*Neue Person in das Gremium aufnehmen*
