# Videos

In diesem Bereich finden Sie Videos, die Ihnen die verschiedenen Bereiche von **Elektra** näherbringen. Die **E-Learning-Videos** stellen die zentralen Module (Aufgaben, Stammdaten, Wahlfunktionen …) im Detail vor. Die **Tutorials** helfen bei konkreten Anwendungsfällen.

Die Videos, die Ihnen bereits in den einzelnen Kapiteln begegnet sind, werden hier noch einmal gesammelt an einem Ort angeboten – so finden Sie alle Inhalte gebündelt wieder, ohne die passenden Kapitel erneut aufsuchen zu müssen.
