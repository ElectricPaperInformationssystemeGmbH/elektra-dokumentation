# „Menü, Tabelle, Maske“ Prinzip

1. Der Aufruf erfolgt über das Hauptmenü oder das **Triptychon**.

1. Anschließend wird eine Funktionsseite mit einer Überschrift und in der Regel einer Tabelle angezeigt.

1. Innerhalb der Tabelle stehen verschiedene Schaltflächen zur Verfügung, über die mit den dargestellten Datensätzen gearbeitet werden kann.

1. Für die Bearbeitung eines Datensatzes öffnet sich eine Eingabemaske.
