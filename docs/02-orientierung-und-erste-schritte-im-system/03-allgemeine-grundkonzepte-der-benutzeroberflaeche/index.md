# Allgemeine Grundkonzepte der Benutzeroberfläche

In der Software **Elektra** kommen an verschiedenen Stellen wiederkehrende Bedienkonzepte zum Einsatz. Diese folgen einheitlichen Mustern und erleichtern die Orientierung sowie die Nutzung des Systems.

Alle Funktionsbereiche sind nach dem gleichen **„Menü, Tabelle, Maske"-Prinzip** aufgebaut:

1. Der Aufruf erfolgt über das Hauptmenü oder das **Triptychon**.
2. Anschließend wird eine Funktionsseite mit einer Überschrift und in der Regel einer Tabelle angezeigt.
3. Innerhalb der Tabelle stehen verschiedene Schaltflächen zur Verfügung, über die mit den dargestellten Datensätzen gearbeitet werden kann.
4. Für die Bearbeitung eines Datensatzes öffnet sich eine Eingabemaske.

Auf den folgenden Seiten lernen Sie die wiederkehrenden Bausteine dieses Prinzips im Detail kennen: die grundlegenden Interaktionen (Schaltflächen und Symbole), den Aufbau und die Funktionen der Tabellen sowie die Bedienung der Dialogboxen.
