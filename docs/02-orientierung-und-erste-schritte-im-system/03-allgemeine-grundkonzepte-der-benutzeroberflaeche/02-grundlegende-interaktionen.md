# Grundlegende Interaktionen

Die folgende Übersicht zeigt die wichtigsten Schaltflächen und Symbole, die Ihnen innerhalb der Tabellenansichten für die Arbeit mit den dargestellten Datensätzen zur Verfügung stehen.

<div className="fieldTable">

| Symbol | Funktion |
| --- | --- |
| ![](img/image30.png) ![](img/image31.png) | **Neues Objekt anlegen:** Dunkel blaue Schaltfläche mit einem **+-Symbol**. Erstellt einen neuen Datensatz. |
| ![](img/image32.png) | **Bearbeiten (Stiftsymbol):** Öffnet die Eingabemaske zur Bearbeitung eines bestehenden Datensatzes. |
| ![](img/image33.png) | **Löschen (Papierkorbsymbol):** Entfernt einen Datensatz. |
| ![](img/image34.png) | **Speichern:** Übernimmt die vorgenommenen Änderungen und schließt die Maske. |
| ![](img/image35.png) | **Abbrechen / Schließen („X“):** Schließt die Maske ohne Speicherung der Änderungen. |
| ![](img/image36.png) | **Dokument generieren:** Erstellt Dokumente auf Basis hinterlegter Vorlagen. |
| ![](img/image37.png) | **Dokument hochladen:** Ermöglicht das Hinterlegen von Dateien zu einem Datensatz. Sobald Sie auf die Fläche klicken, öffnet sich Ihr lokaler Dateiexplorer. Alternativ können Sie ein Dokument mittels „**Drag-and-Drop**“ auf die Fläche ziehen, um es hochzuladen. |
| ![](img/image38.png) | **Dokument herunterladen:** Der nach unten gerichtet Pfeil weist daraufhin, dass Sie hier ein Dokument lokal speichern können. |
| ![](img/image39.png) | **Dokument anzeigen (Augen-symbol):** Öffnet ein bereits hinterlegtes Dokument zur Ansicht oder zum erneuten Download. |

</div>
